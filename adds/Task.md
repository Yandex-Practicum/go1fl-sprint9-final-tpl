# Поиск максимального значения в большом массиве данных
Это практическое задание призвано закрепить ваши знания по теме «Многопоточность». Тема, посвящённая многопоточности в Go, довольно обширная, поэтому сложно охватить все её аспекты в одном небольшом проекте. Самое сложное в многопоточности — это понять, где можно и нужно использовать параллельное выполнение кода. Это итоговое задание демонстрирует один из возможных сценариев использования многопоточности, и как эта возможность языка ускоряет работу с большими массивами данных.

## Техническое задание
Вам предстоит написать небольшую программу, которая будет находить максимальное значение в слайсе целых положительных чисел. Задача тривиальная и решается довольно просто, если решать её в один поток. Но если слайс содержит очень много элементов, например, 10 миллионов, то нахождение максимума может занять какое-то время. При написании проекта вы в этом убедитесь, так как для сравнения вы будете сначала находить максимум в один поток, а потом в 8. Весь код будет в основном пакете main. 
Нужно будет создать три функции. 
## Функция генерации данных generateRandomElements()
Функция должна генерировать числа и записывать в созданный слайс. Функция принимает размер слайса и возвращает слайс с данными. Для генерации случайных чисел используйте функцию из пакета math/rand. Обязательно обработайте крайние случаи, например, если был передан размер слайса, равный 0.
Для этой функции нужно будет сделать unit-тест в файле main_test.go. 
## Функция нахождения максимума maximum()  
Эта функция должна находить максимальное число в слайсе, который передаётся в функцию, и возвращать его. Обязательно обработайте все возможные крайние случаи, чтобы ваша программа не паниковала, когда они произойдут.
Для этой функции нужно будет сделать unit-тест в файле main_test.go. Не забудьте учесть все возможные крайние случаи: пустой слайс, слайс с одним элементом и так далее.
## Функция нахождения максимумов в частях слайса maxChunks()
Эта функция также принимает слайс и возвращает максимальное значение, но работать она будет по-другому.   

Алгоритм функции:
- Чтобы найти максимальное значение быстрее, можно разделить слайс на восемь частей и в каждом из них найти максимум.
- Находить максимумы в каждом из восьми срезов вашего большого слайса нужно будет в отдельных горутинах.
- Все 8 максимальных значений можно сохранить в другом новом слайсе, который нужно будет создать. Таким образом, у вас будет слайс из восьми максимальных значений для каждого среза нашего большого слайса, среди которых вы также сможете найти максимум.
- Для запуска горутин (их будет 8, так как мы решили разделить слайс на 8 частей), создайте переменную типа sync.WaitGroup и используйте её при запуске и ожидании горутин.
Для запуска горутин используйте цикл.  

В цикле:
- Чтобы вычислить размер среза, нужно длину вашего слайса разделить на количество частей — их 8. Для количества частей в прекоде будет объявлена константа CHUNKS.
- Чтобы найти начальный индекс среза, нужно умножить переменную цикла на размер среза.
- Чтобы найти конечный индекс среза, нужно к начальному индексу прибавить размер среза.
Запустите анонимную функцию асинхронно (горутина), которая принимает срез вашего слайса, находит максимум и записывает в слайс максимумов.
Далее нужно найти максимум в вашем слайсе максимумов и вернуть его.
